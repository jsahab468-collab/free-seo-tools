How to use tags well. Put your most important, most specific tag first — YouTube weighs early tags more. Mix exact phrases (“biryani recipe”) with broader ones (“pakistani food”), and don't repeat the same word in ten near-identical tags.

Tags help YouTube understand a video; they don't replace a good title, thumbnail, and description. If a tag doesn't describe your video, leave it out — misleading tags can hurt more than they help.

What “good” looks like. Titles usually display fully up to about 50–60 characters (600 px); descriptions up to about 150–160 characters (920 px). Shorter is safer than longer — a truncated title can cut off your most important words.

Write the description for the person searching, not for Google: one clear promise of what the page delivers, in natural language, with the keyword used once if it fits.

Frequently asked questions

Are these tools really free?

Yes. Every tool on this page is free to use, with no account, no email address, and no usage limit. The tools run entirely in your browser, so there is nothing to pay for on a server.

Is my text sent anywhere?

No. All five tools calculate their results locally, in your browser, using JavaScript on this page. Your titles, descriptions, tags and pasted text are never uploaded, stored, or shared. Closing the tab removes them.

How many YouTube tags should I use?

There is no fixed number — YouTube's limit is 500 characters in total. Most creators use 10–20 relevant tags. Relevance matters far more than quantity: a few exact, honest tags beat a long list of loosely related ones.

Why does the Meta Checker measure pixels as well as characters?

Google truncates titles and descriptions by the width they take up on screen, and a wide letter like “W” takes more room than a narrow one like “i”. Two titles with the same character count can display very differently, so the pixel estimate is the more reliable guide.

Do meta keywords still help rankings?

No — Google has ignored the meta keywords tag for ranking for many years, and it is not included in the generator's main output by default. The generator does include it as an optional field for other tools that may still read it, but it will not improve your position in search results.

Can I use these tools on my phone?

Yes. The page is designed to work on phones and desktops, and every tool — including copy buttons — works with touch. The Meta Checker also has a mobile preview so you can see how a result looks on a small screen.
